# 🎮 Ultimate Tic-Tac-Toe

### VOSC Activity 1

A modern and interactive Tic-Tac-Toe game built using only:

- HTML
- CSS
- JavaScript

No frameworks, libraries, backend or external dependencies are used.

---

## ✨ Features

### 🎮 Game Modes

- Player vs AI
- Player vs Player

### 🤖 AI Levels

- Easy
- Medium
- Hard
- Impossible

The Hard and Impossible modes use the Minimax algorithm for intelligent gameplay.

### 🎨 Themes

The game includes four visual themes:

- Neon
- Ocean
- Sunset
- Emerald

### 📊 Game Statistics

The game tracks:

- Wins
- Losses
- Draws
- Win Rate
- Round number
- Number of moves

Scores are stored using browser Local Storage.

### 🧠 Position Analysis

The game provides:

- Win probability
- Position status
- Suggested best move
- Current move count

### 🔥 Other Features

- Winning-cell animation
- Confetti celebration
- Sound effects
- AI thinking animation
- Undo
- New Round
- Reset Score
- Responsive design
- Mobile support
- Keyboard shortcuts
